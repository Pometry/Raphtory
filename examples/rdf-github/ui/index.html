Raphtory RDF example

YASGUI query editors, preloaded with example queries, on the SPARQL endpoints of the Raphtory server :

  • github: the pull requests, reviews and issues of a GitHub repository
  • people: a small knowledge graph of people and the companies they work for

Each tab shows a table or a graph of its results (switch with the buttons above the results). Add ?asof=2024-01-01 to an endpoint URL to run every query of that tab on the graph as it was on that date.
